# Agentic Foundation provenance

The project contract, delivery/review workflow and GitHub task/PR templates adapt [Agentic Foundation](https://github.com/nullabletype/agentic-foundation) `0.2.0-draft.7`, commit `5eb483e`, for ShipItSharp's supervised CLI workflow. Adoption was prepared on 4 November 2026. The retained [MIT notice](../LICENSES/agentic-foundation.txt) covers that material. ShipItSharp's application licence remains in [LICENSE.txt](../LICENSE.txt).

Upstream credits Matt Pocock and [Skills for Real Engineers](https://github.com/mattpocock/skills) for requirements grilling, prototypes, domain modelling, bounded tickets and code review. OpenAI and Anthropic engineering publications informed the upstream loop. The upstream [credits](https://github.com/nullabletype/agentic-foundation/blob/5eb483e/CREDITS.md) record attribution and provenance. No third-party skill bodies or evaluation toolkit are vendored here.

This adaptation selects a small project contract, implementation/review loop and handoff format. It uses ShipItSharp's existing tests and LikeC4 source. Publication is explicitly authorised per task during the pilot. Enforcement gaps are recorded in PROJECT.md for a separate change before unattended execution.
